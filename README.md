# 🛒 Groceria-WA

A modern **Grocery Shopping Web App** built with **React + Vite** that allows users to order vegetables, fruits, and daily groceries directly via **WhatsApp** for fast delivery 🚀

---

## 🌟 Features

- 🥦 Fresh Vegetables & Fruits  
- 🛍️ Daily Grocery Items  
- 🛒 Add to Cart / Remove Items  
- 🔢 Quantity Management  
- 💰 Auto Price Calculation  
- 📍 Checkout with Name & Address  
- 📲 WhatsApp Order Integration  
- ⏱️ 30-Minute Delivery System  
- 💳 Cash on Delivery / UPI Payment  

---

## 🧠 How It Works

1. Browse grocery items 🥕🍎  
2. Add items to cart  
3. Go to checkout page  
4. Enter:
   - Name  
   - Phone Number  
   - Address  
5. Click **Place Order**  
6. WhatsApp opens with order details  
7. User sends message (and payment screenshot if paid)
